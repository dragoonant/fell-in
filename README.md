# Fell-in: Wasteland Warfair

A fan-made 3D browser skirmish game on a dusty 3 by 3 foot wasteland table, with the mechanics of a post-apocalyptic
miniatures game and entirely original art and text. By evilgouki.

Run it: `npm install`, then `npm run dev` (port 5191 via `.claude/launch.json`, or Vite's default), `npm test` for the
unit tests, `npm run build` for the Pages build served under `/fell-in/`.

This is an unofficial fan project. It is not affiliated with Modiphius Entertainment, Bethesda Softworks or ZeniMax.
