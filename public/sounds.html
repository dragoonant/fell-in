Sound audition

Tap an id to play it; tapping another stops the first. Music can loop to check the seam. Name the ids to redo and they get regenerated with a new seed.

Synthesised fallback

The built-in synth plays when a file is missing. Auditioning it needs the dev server (npm run dev), which serves its source; on the published site this section says so.
